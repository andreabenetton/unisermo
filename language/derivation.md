# Derivational Morphology

Derivational morphology builds lexical items before case marking. Nominal
plurality with `wi` is analytic and therefore precedes the resulting noun
phrase rather than attaching inside the derived word.

## 1. Productive suffixes

| Function | Suffix | Example | Meaning |
|---|---|---|---|
| person / agent | `-or` | `fakor` | maker / doer |
| tool / instrument / device | `-il` | `fakil` | making tool/device |
| place / institution / field / domain | `-ia` | `fakia` | workshop / making domain |
| participial / resultative | `-it` | `fakit` | done / made |
| abstract quality / state / property | `-itat` | `klaritat` | clarity |
| relational adjective | `-al` | `fakal` | related to making |

## 2. Agent and instrumental derivation

The productive suffix **`-or`** derives a person whose characteristic role or
activity is to perform the action expressed by the base. It is the canonical
person/agent suffix; historical `-er` is retired from this function.

The productive suffix **`-il`** derives an object, tool, machine, device, or
artifact whose characteristic function is to perform, facilitate, or enable
the action expressed by the base.

Examples:

- `fak` → `fakor` — maker / person who makes
- `fak` → `fakil` — making tool / device
- `dok` → `dokor` — teacher / person who teaches
- `vid` → `vidil` — viewing / observation instrument

Derivational parsing is based on a canonical base plus a productive suffix,
not on spelling alone. A lexical or grammatical word that merely ends in
`-or` is not automatically segmented. In particular, `major` and `minor` are
indivisible comparison words, not agentive derivations.

The free relator `per` remains the analytic instrumental/perlative marker
("through; by means of"). Thus `-il` creates the lexical name of an instrument,
while `per + NP` marks use of a noun phrase as the means in a clause.

## 3. `-ia` is hiatus

`-ia` remains canonical and is pronounced **/i.a/**. Adjacent written vowels
remain vowels; the suffix is not `/ja/`.

Examples:

- `fak + ia` → `fakia` /fa.ki.a/
- `dok + ia` → `dokia` /do.ki.a/
- `med + ia` → `media` /me.di.a/

## 4. Participial/resultative `-it`

`-it` is productive on verb roots:

- `dik` → `dikit` — said
- `mov` → `movit` — moved
- `vid` → `vidit` — seen
- `fak` → `fakit` — done / made

The same `-it` form may be zero-nominalized as a result noun. Thus `fakit` can
mean a fact / thing done when used nominally; `wi fakit` is the explicit plural
and `duo fakit` means two facts / two things done. Nominalized participles take
ordinary noun number and case marking and do not receive a special plural
suffix.

## 5. Abstract `-itat`

`-itat` replaces the historical abstract use of `-it`:

- `bon` → `bonitat` — goodness
- `klar` → `klaritat` — clarity
- `uman` → `umanitat` — humanity

## 6. Other productive suffixes

- `-or` — person/agent
- `-il` — tool/instrument/device
- `-al` — relational adjective

## 7. Prefixes retained from the original system

The following productive prefixes remain available unless a future lexical
collision requires a root-specific revision:

`no-`, `anti-`, `de-`, `re-`, `pre-`, `pos-`, `ko-`, `auto-`, `semi-`,
`multi-`, `neo-`, `super-`, `sub-`, `mikro-`, `makro-`.

Examples must use current roots, e.g. `refak`, `defak`, `autofak`, not obsolete
`refac`, `defac`, `autofac`.


### Canonical phase prefixes

A restricted, semantically compositional phase family is canonical with the
prefixes `in-`, `ad-`, `de-`, and `re-`. The prefix and root are written as one
word, without a hyphen. Their invariant phase meanings are:

- `in-` — remain / continue in the base event or state
- `ad-` — enter / begin the base event or state
- `de-` — leave / cease the base event or state
- `re-` — return / resume the base event or state

With `es`, this yields `ines`, `ades`, `dees`, `rees`. With `mov`, the same
architecture yields `inmov`, `admov`, `demov`, `remov`: continue moving, begin
moving, cease moving, and resume moving. The exact lexical translation depends
on the semantic type of the base, but the phase relation contributed by the
prefix remains constant.

These phase prefixes do not encode progressive/perfect aspect. Finite aspect
remains the separate canonical `Ø/e/o` slot.

### `mov` valency alternation

The `mov` family has a canonical intransitive/transitive valency alternation.
With no accusative object, the subject is the moving entity; with an accusative
`X-em`, the subject is the external mover/causer and `X-em` is the entity whose
motion is controlled.

```text
X-NOM mov                 = X moves
Y-NOM mov X-em            = Y moves / displaces X
Y-NOM mov X-em DEST-ad    = Y moves / displaces X toward DEST
```

The same alternation applies compositionally to the phase-derived members:

- `X admov` = X begins moving; `Y admov X-em` = Y sets X in motion
- `X inmov` = X continues moving; `Y inmov X-em` = Y keeps X in motion
- `X demov` = X stops moving; `Y demov X-em` = Y stops X
- `X remov` = X resumes moving; `Y remov X-em` = Y sets X moving again / restarts X's motion

`inmov` does **not** mean "push" or "pull". It contributes only continuation
of motion; the physical manner or force relation of pushing and pulling is a
separate lexical matter. Likewise, this valency alternation does not replace
finite aspect morphology: progressive `mov-e-...` means that motion is ongoing,
whereas `inmov` presupposes an already established motion and asserts its
continuation.


### Explicit transition between states

The canonical verb `traes` expresses transition from one explicitly named state
to another. Its frame reuses the synthetic case system:

```text
traes DEST-ad SOURCE-de
```

Thus `traes solidad likwidde` means "pass from liquid to solid". This differs
from `ades solid`, which simply means "become solid" and leaves the source state
unspecified. `traes` does not create a new phase prefix and does not replace
`ades`; it is the two-pole transition construction.

A second canonical `traes` frame is transitive and causative:

```text
Y-NOM traes X-em RESULT-da
```

Here `-em` marks the entity being transformed and resultative/transformative
`-da` marks the state, role, class, or property produced by the transformation.
For example, `Y traes akwaem solidda` means "Y transforms the water, making it
solid". `-da` is a nominal case relation in this frame, not a derivational
suffix and not a replacement for allative `-ad`.

## 8. Inflection after derivation

Case suffixes follow the fully derived lexical word:

- `fakorem` — maker as direct object
- `klaritatem` — clarity as direct object
- `fakias` — of the workshop/domain

Explicit plural `wi` remains a separate pre-nominal particle:

- `wi fakor` — makers
- `wi fakorem` — makers as direct object

The historical nominal plural suffix `-en` is not part of the current system.
