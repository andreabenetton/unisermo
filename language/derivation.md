# Derivational Morphology

Derivational morphology builds lexical items before case marking. Nominal
plurality with `wi` is analytic and therefore precedes the resulting noun
phrase rather than attaching inside the derived word.

## 1. Productive suffixes

| Function | Suffix | Example | Meaning |
|---|---|---|---|
| person / agent | `-er` | `faker` | maker / doer |
| tool / instrument / device | `-or` | `fakor` | making tool/device |
| place / institution / field / domain | `-ia` | `fakia` | workshop / making domain |
| participial / resultative | `-it` | `fakit` | done / made |
| abstract quality / state / property | `-itat` | `klaritat` | clarity |
| relational adjective | `-al` | `fakal` | related to making |

## 2. `-ia` is hiatus

`-ia` remains canonical and is pronounced **/i.a/**. Adjacent written vowels
remain vowels; the suffix is not `/ja/`.

Examples:

- `fak + ia` → `fakia` /fa.ki.a/
- `dots + ia` → `dotsia` /dot.si.a/
- `med + ia` → `media` /me.di.a/

## 3. Participial/resultative `-it`

`-it` is productive on verb roots:

- `dik` → `dikit` — said
- `mov` → `movit` — moved
- `vid` → `vidit` — seen
- `fak` → `fakit` — done / made

The same `-it` form may be zero-nominalized as a result noun. Thus `fakit` can
mean a fact / thing done when used nominally; `wi fakit` is the explicit plural
and `duo fakit` means two facts / two things done. Nominalized participles take
ordinary noun number and case marking and do not receive a special plural
suffix.

## 4. Abstract `-itat`

`-itat` replaces the historical abstract use of `-it`:

- `bon` → `bonitat` — goodness
- `klar` → `klaritat` — clarity
- `uman` → `umanitat` — humanity

## 5. Other productive suffixes

- `-er` — person/agent
- `-or` — instrument/device
- `-al` — relational adjective

## 6. Prefixes retained from the original system

The following productive prefixes remain available unless a future lexical
collision requires a root-specific revision:

`no-`, `anti-`, `de-`, `re-`, `pre-`, `pos-`, `ko-`, `auto-`, `semi-`,
`multi-`, `neo-`, `super-`, `sub-`, `mikro-`, `makro-`.

Examples must use current roots, e.g. `refak`, `defak`, `autofak`, not obsolete
`refac`, `defac`, `autofac`.

## 7. Inflection after derivation

Case suffixes follow the fully derived lexical word:

- `fakerem` — maker as direct object
- `klaritatem` — clarity as direct object
- `fakias` — of the workshop/domain

Explicit plural `wi` remains a separate pre-nominal particle:

- `wi faker` — makers
- `wi fakerem` — makers as direct object

The historical nominal plural suffix `-en` is not part of the current system.
