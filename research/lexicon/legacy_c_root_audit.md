# Legacy/source roots containing `c`

> **Status:** normative migration table. Confirmed 2026-08-09.

The current alphabet has no letter `c`. The following legacy/source roots have
now been assigned canonical GlottoDelta replacements. Historical/source `c` is
still adapted root-by-root; this table records the decisions rather than a
global conversion rule.

| Legacy root | Canonical root | Italian gloss | Latin source |
|---|---|---|---|
| `act` | `ager` | agire; atto; azione | `agere` |
| `cad` | `kad` | cadere | `cadere` |
| `cap` | `kap` | prendere; catturare | `capere` |
| `centr` | `sentrum` | centro; centrale | `centrum` |
| `cert` | `sert` | certo; certezza | `certus` |
| `circul` | `sirkul` | cerchio; circolare | `circulus` |
| `civ` | `siv` | cittadino; civile | `civis` |
| `clar` | `klar` | chiaro; chiarezza | `clarus` |
| `com` | `kom` | con-; insieme | `cum / com-` |
| `cred` | `kred` | credere; credito | `credere` |
| `cur` | `kur` | cura; curare | `cura` |
| `dec` | `dek` | dieci; decimale | `decem` |
| `dict` | `dik` | dire; detto; dettare | `dicere` |
| `direct` | `dirig` | dirigere; diretto | `dirigere` |
| `doc` | `dots` | insegnare; docente | `docere` |
| `fac` | `fak` | fare; creare | `facere` |
| `loc` | `lok` | luogo; locale | `locus` |

| `struct` | `stru` | costruire; struttura | `struere` |
| `voc` | `vok` | voce; chiamare | `vox` |
| `cin` | `kin` | cinque | `quinque` |
| `nacion` | `nation` | nazione | `natio, nationis` |

The user-supplied candidate `sircul` was normalized to **`sirkul`** because
letter `c` is not part of the canonical GlottoDelta alphabet.

These are lexical decisions. They do not create a mechanical source `c`
conversion rule for future roots.
