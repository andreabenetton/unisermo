# Lexicon design workspace

Confirmed lexical choices and migration audits belong here.

- `confirmed_lexicon.json` — machine-readable confirmed forms.
- `legacy_c_root_audit.md` — source/legacy roots containing historical `c`, to
  be adapted root by root under the current alphabet.

- `confirmed_lexicon.json` and `legacy_c_root_audit.md` now contain the confirmed legacy-c root migration set.

## Kinship restoration (24 October 2026)

The confirmed lexicon now contains **`adel` (sibling), `adelo` (brother), `adele` (sister)**. Their original 10 August author acceptance had been missed in Git. The project author explicitly directed replacing historical `frat`, which now appears only in historical evidence and archived benchmark compatibility data, **not the confirmed lexicon**. See [`language/kinship.md`](../../language/kinship.md) and [source history](../history/august-kinship-original-dialogue-versus-git.md). Parent `gen/geno/gene` and uncle/aunt `adelgen` are now author-approved and confirmed; grandparent `bisjergen` follows the `NUMjer` rule. Offspring `fil` is now author-ratified, `filadelgen` has become the confirmed first-cousin composition, and typed maternal/paternal grandparent paths `genegene`, `genegeno`, `genogene`, `genogeno` are explicitly defined. The unapproved `filo/file` derivatives and broader kinship candidates remain open.
