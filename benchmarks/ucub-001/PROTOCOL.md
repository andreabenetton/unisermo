# UCUB-001 — Compositional Understanding Benchmark (experimental protocol)

Status: **proposed / not yet executed**. Research only: no language ratification.
Repository: `andreabenetton/unisermo`. Frozen legacy benchmarks MUST remain unchanged.

## Research question

Can an LLM apply a short, explicit, compositional Unisermo grammar to *unseen combinations* and derive valid conclusions, rather than merely translate or guess from international-looking roots?

This design does not establish absence from pretraining. The cold condition is a zero-information prompt, **not** proof of zero exposure.

## Corpus version and provenance

New `benchmarks/corpus/ucub-001/` namespace with immutable, separately versioned case manifest, parser/grammar/lexicon commit SHA, generator revision and SHA-256 for each artifact. Never repair previous corpus or its scores in place. Historical `frat` is excluded from new canonical cases.

Target **80 independent semantic cases**, 20 per level; development=60 (15 per level), held-out=20 (5 per level), grouped by minimal-pair family and lexical/template family to prevent pair leakage. The 80 must be **individually reviewed and frozen before scored runs**, rather than autogenerated by repeating trivially similar templates. Document randomization algorithm and seed; do not silently regenerate holdout. Mark any parser-unsupported case as separately human-verified and report parser coverage.

## Levels

1. **Compositional grammar** (20): cases/genitives, derivation, source/goal/location, TAM, valency, modal complements. Extract typed events and attachment. Do not include unratified construction combinations.
2. **Minimal semantic contrasts** (20): modal vs action negation, `pos` vs `pot` vs `sap` vs `aut` vs `deb`, movement vs choice, local vs permitted wide scope, permission-source attachment. Pair related items within one split; contrast probes must specify a testable divergent property.
3. **Cross-clause logic** (20): conditional/coordination and explicitly ratified `no lim` scope; ask separately for entailed, contradicted, and undetermined hypotheses. Use a separate reviewed truth-condition gold; do not treat the parser AST as proof of entailment. Exclude unsupported `no lim` scopes over `ma`, `due`, `nam`, `ergo`, `se`, etc.
4. **Short discourse** (20): 3–5 propositions, cross-sentence agent/object/time and reference tracking; distinguish contradictions, missing facts, tense and participant changes. Only score discourse bindings defined in a reviewed gold.

All levels should contain positive and negative probes; counterbalance English lexical priors; avoid overly frequent repeated wording. An uncertain/unratified linguistic feature is **not** a model error.

## Conditions (fresh isolated context for every request)

- A **Cold:** Unisermo input and standardized task/output schema only.
- B **Lexicon:** A plus the minimal, *case-independent*, canonically sourced roots and meanings, no grammar rules.
- C **Grammar:** B plus a fixed, versioned, concise grammar sheet (identical within the tested model and split). The grammar must cover the tested phenomena but contain **no scored examples or paraphrases**.
- D **English reasoning control:** Independently validated controlled-English semantic equivalent and identical task/output schema. This is a reasoning ceiling/control, not a language-free baseline.

No accumulated conversational history, few-shot exemplars, parser outputs, gold labels, or other test cases in the model's prompt. Construct per-condition input deterministically; exclude test/holdout answers from condition C sheet.

## Gold and scoring

Each item records: `case_id`, `level`, `family_id`, `split`, `unisermo`, `english_control`, `parser_status`, `grammar_refs`, `lexicon_refs`, `expected_structure`, `role_bindings`, `hypotheses` (each `entailed|contradicted|undetermined`), `ambiguity_status`, `gold_review_status`, `reviewer_id`.

Score independently:
- structural exact match and slot-level F1 (including tense and aspect);
- semantic-role accuracy and attachment;
- entailment macro-F1 / false entailment rate, with `undetermined` explicitly distinct from false;
- ambiguity recognition precision/recall and abstention calibration;
- minimal-pair **contrast consistency**: both sides correct and their difference preserved;
- invalid JSON, missing answer, provider failure and refusal separately;
- provider-reported prompt/completion tokens and billed cost, plus **cost per correctly answered case** (report denominator and zero-success as undefined, not infinity or zero).

Macro-aggregate by level and model/condition, with counts and uncertainty intervals. Do not count multiple hypotheses on one discourse as independent samples when computing confidence intervals: resample by case or family. Baseline `13/18` refers to a *different pilot and metric*, and is not directly comparable.

## Execution and leakage safeguards

Pilot first on `qwen/qwen3-32b` and `google/gemma-3-27b-it` (historically used through OpenRouter), pinned exact returned model/provider identifiers, provider routing, prompt hashes, parameter values and date. Existing `benchmarks/openrouter_runner.py` is reusable in part, but its `MAX_PER_MODEL=72`, `MAX_OUTPUT=48`, and Qwen-specific `temperature=0.7`/`/no_think` require explicit handling; **do not invoke the old runner directly for the full UCUB matrix**.

Run development smoke checks first. Freeze corpus, prompts, grammar-sheet and gold *before* any holdout calls; report development/holdout separately. Use fixed parameters as supported, multiple fixed seeds/repetitions if nondeterminism matters; record reasoning-mode differences explicitly and ensure adequate output budget for structured responses. Protect API keys; fail closed if credentials/provider unavailable. Never fabricate runs, tokenizer measurements or results.

Expected scored matrix per single pass: 80 cases × 4 conditions × 2 models = **640 requests**, excluding retries and repetitions. Set preflight cost/request caps and resumable append-only files, with per-request metadata and raw response; never overwrite.

## Acceptance gates

1. All 80 cases ratification-consistent, versioned and independently semantically reviewed, including English controls.
2. Parser pass/skip rates published with reason for every skip; no parser extension solely to make the benchmark pass.
3. Frozen leakage-safe split and minimal-pair grouping verified.
4. Frozen prompt/grammar/lexicon snapshots, hashes and preflight request budget verified.
5. Development smoke succeeds; holdout remains unopened until full protocol is frozen.
6. Final report discloses model versions, provider, coverage, all denominators, failure classes, costs, limitations and uncertainty.
