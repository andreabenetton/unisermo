## Original scoring defect

The original scorer required bare JSON with no wrapping markup. **All 32 original outputs are valid single-label JSON objects inside complete ```json Markdown fences**. Hence original scorer `@1` classified 32/32 as invalid and gave 0 accuracy for every arm.

Correction to analysis: `score@2` distinguishes **raw JSON contract compliance** (still 0/32) from **semantic label recoverability**. The recovery removes one entire Markdown JSON fence, accepts the inner object only if it matches the same exact one-field `{"label": ...}` schema, and rejects arbitrary prose or partial/embedded objects. The original output is never rewritten. This repair changes scoring only: **no new billed LLM calls**.

## Limits and next gate

1. The pilot exercises **only the simplest level L1**. It cannot establish whether a model understands modal scope, likelihood, multi-clause reasoning or new quantitative construction.
2. English paraphrases and gold judgments are *not independently validated*. This is a diagnostic smoke test, **not** evidence that Unisermo outperforms other languages.
3. Arms are paired, but instructional prompt length and generation parameters vary, and the sample is only four unique items.
4. For broader model evaluation, commission independent human review of semantic gold, freeze the reviewed split and instruction variants, then run a **stratified development sample covering all four levels**; reserve the 16-case holdout.
5. Future runner results must report strict-format compliance **separately** from conservatively recovered semantic-label accuracy; requests should consider API-native JSON response format when supported and document that change as a distinct prompt/protocol variant.
